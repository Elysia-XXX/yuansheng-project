# 前端参考与适配

参考来源：用户指定的本地项目 `D:\DeepFrontier\frontend`。该目录仅作为只读设计参考，没有修改或迁移其 Next.js 项目。

## 参考位置

- `src/styles/globals.css`：暖白背景、低饱和侧栏、黑灰主色、细边框及圆角。
- `src/components/workspace/workspace-sidebar.tsx`、`workspace-header.tsx`：可折叠导航、顶部新建入口、侧栏最近会话。
- `src/components/workspace/welcome.tsx`：品牌图标、居中名称与简短引导。
- `src/components/workspace/native-input-box.tsx`：大圆角输入框、底部工具栏、圆形发送按钮。
- `src/components/workspace/chats/chat-box.tsx`：对话为主，右侧结果面板按需展开。

## 原声中的实现

保留 Vue 3 + Flask 架构和原声业务功能，按上述设计语言实现：

1. 暖白背景，复用参考的 background/sidebar/accent/border 色值；黑灰文字与单色线性图标，数据图表用低饱和橄榄灰。
2. 左侧导航宽248px，可折叠到60px；最近对话直接切换。手机端使用可关闭抽屉，关闭时隐藏导航的键盘焦点。
3. 空对话时居中显示原声标识、标题与输入框；示例操作以小型胶囊呈现。
4. 对话产生工具结果后展开分析依据，可关闭并通过工具调用按钮重新打开；窄屏下作为侧面浮层显示。
5. 会话状态抽到 `src/composables/useWorkspace.ts`，侧栏与对话共用数据。保持本地存储键名，已有会话继续可用。
6. `AppIcon.vue` 统一线性图标，图形标记仍使用原声波形，产品名称保持原声 Agent。

未复制参考项目的账户、模型选择、技能、媒体生成等交互入口；它们需要对应后端能力，不能仅通过外观暗示已经支持。右栏目前支持展开/关闭，未加入参考项目的拖拽调整尺寸。

## 验证方式

运行前端生产构建验证 TypeScript 和两个 HTML 入口；通过浏览器检查新建对话、会话切换、侧栏折叠、示例查询、计算、结果面板开关、执行记录及手机抽屉导航。后端接口和工具定义不因此次外观适配而改变。
