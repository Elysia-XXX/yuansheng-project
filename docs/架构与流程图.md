## 三、制作流程图（数据处理流水线）

```
                 ┌────────────────────────────────────────────────┐
                 │  ① 数据采集 / 录入（订单·CRM·工单·评价）            │
                 │  触点 S1客服聊天 S2商品评价 S3退货 S4问大家 S5工单   │
                 └───────────────────────┬────────────────────────┘
                                         │ xlsx / 接口 JSON
                                         ▼
                 ┌────────────────────────────────────────────────┐
                 │  ② 数据解析与清洗（dataset.py）                    │
                 │  · 定位字段名行（英文列名/中文别名归一）             │
                 │  · 类型转换：金额→float、是否→bool、时间→ISO        │
                 │  · 必填校验：商品ID+客户原文 或 完整字段             │
                 └───────────────────────┬────────────────────────┘
                                         │
                                         ▼
                 ┌────────────────────────────────────────────────┐
                 │  ③ 商品目录补齐（product_catalog）               │
                 │  source_product_id → SKU + 品类三级               │
                 │  未匹配 → 缺省标记「其他/未识别/待人工确认」         │
                 └───────────────────────┬────────────────────────┘
                                         ▼
                 ┌────────────────────────────────────────────────┐
                 │  ④ 落库 dataset_info（表一：业务/画像/交易字段）    │
                 └───────────────────────┬────────────────────────┘
                                         ▼
                 ┌────────────────────────────────────────────────┐
                 │  ⑤ MiMo 智能打标（complaint_analyzer）            │
                 │  输入：客户原文+品类+SKU+平台+在保+生命周期          │
                 │  输出（Pydantic 强类型约束）：                     │
                 │   · 功能标签 C1~C10（一级+二级子标签）              │
                 │   · 生产环节/子环节、部件大类/具体部件              │
                 │   · 语义：评价等级、情绪、问题性质、关键词簇、诉求    │
                 │  校验失败 → 携带错误信息重试（最多 3 次）           │
                 └───────────────────────┬────────────────────────┘
                                         ▼
                 ┌────────────────────────────────────────────────┐
                 │  ⑥ 落库 analysis_result（表二：分析标签，FK关联）   │
                 └───────────────────────┬────────────────────────┘
                                         ▼
              ┌──────────────────────────┼──────────────────────────┐
              ▼                          ▼                          ▼
   ┌────────────────────┐   ┌────────────────────┐   ┌────────────────────┐
   │ ⑦a 聚合洞察          │   │ ⑦b 看板统计         │   │ ⑦c 评价列表/下钻     │
   │ 真实样本(≤200) →     │   │ 8 维度×12 月趋势    │   │ 按品类/标签/状态     │
   │ 结论+2~6条建议       │   │ TOP/占比/环比        │   │ 过滤、分页、详情     │
   └────────────────────┘   └────────────────────┘   └────────────────────┘
                                         │
                                         ▼
                 ┌────────────────────────────────────────────────┐
                 │  ⑧ 输出：客服响应建议 / 产品&质量改善 / 品牌风险      │
                 │    决策人人工复核 → 关闭客诉闭环                    │
                 └────────────────────────────────────────────────┘
```

## 关键数据流一句话总结

`xlsx/单条录入 → dataset_info（表一）→ MiMo 结构化打标（Pydantic 校验重试）→ analysis_result（表二）→ 看板/列表/聚合洞察 → 人工处置闭环`
