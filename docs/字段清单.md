# 字段清单：数据来源分类

依据 `客诉标签分类_整理版.xlsx` 的标签体系（12 个 Sheet），按信息来源分为两张表：

- **表一**：数据集需要提供的信息（+ 客户原文）——由订单/CRM/工单/评价等业务数据直接提供，或由原文本包含
- **表二**：需要从对话中分析的信息——需结合客户原文由分析模型打标得出

---

## 表一：数据集需要提供的信息（含客户原文）

### 客户原文与来源渠道

| 字段 | 说明 | 对应 Sheet/列 | 是否必需 |
| ---- | ---- | ------------- | -------- |
| customer_transcript | **客户原文**（按触点渠道提取的有效抱怨） | 触点渠道.提取有效抱怨 | 是 |
| touchpoint | 触点渠道编码（S1 客服聊天 / S2 商品评价 / S3 退货原因 / S4 问大家 / S5 工单售后） | 触点渠道 | 是 |
| source_form | 原始形态（多轮对话流 / 评分+文本+图片 / 下拉选项+补充 / Q→多A对 / 工单流程） | 触点渠道.原始形态 | 否 |

### 品类（SKU 级）

| 字段 | 说明 | 对应 Sheet/列 | 是否必需 |
| ---- | ---- | ------------- | -------- |
| category_l1 | 一级分类（厨电 / 生活小家电 / 个护小家电 / 母婴小家电 / 其他） | 品类.一级分类 | 是 |
| category_l2 | 二级分类（锅煲类 / 电热类 / 壶类 / 西式类 / 电动类 / 环境电器…） | 品类.二级分类 | 是 |
| category_l3 | 三级分类（电炖盅 / 养生壶 / 破壁机…） | 品类.三级分类 | 是 |
| sku | SKU 编码（如 DDH-208） | 品类.sku | 是 |

| 字段 | 说明 | 对应 Sheet/列 | 是否必需 |
| ---- | ---- | ------------- | -------- |

| use_scene | 使用场景（自用/母婴/送礼/租房/办公室/宿舍/老人独居） | 客户画像.使用场景 | 否 |
| user_type | 用户类型（新客·首购/老客/复购/流失召回） | 客户画像.用户类型 | 否 |

### 订单交易

## 表二：需要从对话中分析的信息

| 字段 | 说明 | 对应 Sheet/列 | 是否必需 |
